# Ruang Hemat — Retail Campaign Concept

Demo landing page kampanye retail berbahasa Indonesia, dibuat sebagai eksplorasi desain. Tidak berafiliasi dengan Alfamart atau merek tertentu. Produk dan penawaran di dalam halaman adalah ilustrasi; bukan promo aktual.

## Menjalankan proyek

```bash
npm install
npm run dev
```

Untuk build produksi:

```bash
npm run build
npm run preview
```

## Teknologi

- React + Vite
- Framer Motion untuk transisi dan micro-interactions
- GSAP ScrollTrigger untuk animasi reveal dan perjalanan langkah
- CSS untuk visual produk bergaya 3D yang ringan tanpa aset 3D berat

Ganti identitas konsep, aset, nama produk, harga, dan mekanisme hanya dengan materi kampanye resmi yang telah disetujui. Perhatikan bahwa ilustrasi produk saat ini dibuat dengan CSS dan Google Fonts memerlukan koneksi internet.
